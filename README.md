# madfauzy.com

Modern Backend Engineering Portfolio & Interactive Systems Architecture Labs.

Built with **Tailwind CSS v4**, **GSAP**, **Lenis Kinetic Smooth Scrolling**, and Vector SVG Architecture Simulators.

- **Portfolio**: [https://madfauzy.com](https://madfauzy.com)
- **Architecture Labs**: [https://madfauzy.com/labs](https://madfauzy.com/labs)

## Tech Stack
- **Frameworks & Languages**: Laravel, Golang, Node.js (JavaScript)
- **Database & In-Memory**: MySQL, PostgreSQL, Redis
- **Cloud & DevOps**: AWS (Lambda, API Gateway, ECS, RDS), Docker, Jenkins CI/CD, Nginx, Linux (Ubuntu)
- **Interactive Labs**: Pure Vector SVG Schematics, GSAP MotionPath animation engine
